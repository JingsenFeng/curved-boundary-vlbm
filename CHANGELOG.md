# Changelog

## 1.0.0 — 2026-09-06

- D2Q4×6 and D3Q6×12 total-Lagrangian hyperelastic solvers in an installable package.
- Curved Dirichlet interpolation and local characteristic traction reconstruction.
- BGK source correction for general relaxation parameters and second-order one-sided gradients.
- Reproduction commands for the manuscript benchmarks with shared traction settings.
- Planar and three-dimensional FEM reference generators, reference arrays, and figure scripts.
- CPU/CUDA numerical tests, regression fixtures, and automated GitHub checks.
- Frozen-source boundary initialization prevents opposing cut links from reading
  populations being updated by another link.
